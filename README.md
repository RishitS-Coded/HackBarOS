# HackBarOS

1. Push commits to `main` or open **Actions** -> **Build HackBar macOS-Styled Mint 22.3 ISO** -> **Run workflow**.
2. Wait for the `build-iso` job to complete building and repackaging the Mint 22.3 XFCE ISO.
3. Open the **Releases** tab on your GitHub repository.
4. Locate the release tagged `iso-<run_number>` (such as `HackBar macOS-Styled Linux Mint 22.3 XFCE (<run_number>)`).
5. Download `work/hackbar-mint-22.3-xfce-amd64.iso` and flash it to a USB drive for authorized educational testing.
